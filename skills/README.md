# Skills

Three skills the runs lean on. An owner adds them under organization settings so everyone gets them at once ([how, from Anthropic's help center](https://support.claude.com/en/articles/13119606-provision-and-manage-skills-for-your-organization), checked Nov 15, 2026). To add one, zip its folder (the zip must contain `SKILL.md`) and upload it.

| Skill | What it does | Before you upload |
|---|---|---|
| `receipts-gate/` | The blind check described in `learn/04-receipts.md` | Nothing to fill in; it reads your company rules for the source map |
| `brand-template/` | Your house style, as a fallback when the brand file can't be read | Fill every placeholder and rename the folder |
| `writing-cleanup/` | The final pass on anything another person reads | Nothing to fill in. Note its license (below) |
